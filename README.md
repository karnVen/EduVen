## 🌟 Overview

**EduVen** is an interactive educational platform designed to make learning engaging and futuristic. We combine standard educational resources with **immersive 3D models**, a **smart syllabus chatbot**, and a **gamified learning experience** powered by advanced automation.

## ✨ Key Features

### 🧊 3D Immersive Learning
Forget boring 2D text. EduVen integrates **Spline 3D models** directly into the interface, making the UI pop and providing an interactive visual experience for students.

### 🤖 NCERT Syllabus Chatbot
Stuck on a topic? Our dedicated **NCERT Chatbot** is trained to answer all your syllabus-related questions instantly.
- **Smart Responses:** Ask specific questions from your textbooks.
- **Instant Help:** No need to search through hundreds of pages.

### 🎮 Game Zone (Powered by n8n)
Learning doesn't have to be boring.
- **Topic-Based Search:** Just type a topic (e.g., "Math", "Physics").
- **n8n Automation:** Our backend workflow automatically fetches relevant educational games from **GitHub** and delivers them to you instantly.

### 🌐 Community Hub
A centralized space connecting you to multiple top-tier education websites and resources. One tab, infinite knowledge.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript

* **Automation:** n8n (Workflow Automation)

## 🚀 Getting Started

Follow these steps to run EduVen on your local machine:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/karnVen/EduVen.git](https://github.com/karnVen/EduVen.git)
    ```
2.  **Navigate to the Directory**
    ```bash
    cd EduVen
    ```
3.  **Install Dependencies** (if applicable)
    ```bash
    npm install
    ```
4.  **Launch the App**
    * Open `home.html` in your browser to start the experience!
